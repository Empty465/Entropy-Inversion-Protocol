# 엔트로피 역전 프로토콜

**Entropy Inversion Protocol**은 Minecraft Forge 1.20.1용 모드입니다.

은하 너머의 오버테크놀로지 무기로 지정한 좌표를 타격하고, 그 주변의 지형과 엔티티를 소멸시킵니다.

> [!CAUTION]
> 타격은 지형을 영구적으로 파괴합니다. 사용 전에 월드를 백업하세요.

## 빠른 시작

1. 크리에이티브 모드의 **도구 및 유틸리티** 탭에서 엔트로피 역전 요청기를 획득합니다.
2. 아이템을 들고 우클릭해 조준 모드에 들어갑니다.
3. 바라보는 블록을 짧게 좌클릭해 목표를 지정합니다. 다른 블록을 짧게 좌클릭하면 목표를 변경할 수 있습니다.
4. 타격 반경을 설정한 뒤 좌클릭을 1초 동안 길게 눌러 타격을 요청합니다.
5. 10초 카운트다운이 끝나면 지정 위치에 타격이 발생합니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 우클릭 | 조준 모드 진입 |
| 짧게 좌클릭 | 바라보는 블록을 목표로 지정하거나 변경 |
| 좌클릭 1초간 누르기 | 지정된 목표에 타격 요청 |
| 마우스 휠 | 반경을 5블록씩 조정 |
| Alt + 마우스 휠 | 반경을 1블록씩 정밀 조정 |
| 우클릭 또는 Esc | 조준 취소 |

조준 모드에서는 마우스 휠로 핫바 슬롯이 바뀌지 않습니다. 첫 조준의 기본 반경은 **10블록**이며, 반경을 변경하면 다음 조준에도 마지막 값이 유지됩니다. 반경은 1~200블록까지 설정할 수 있습니다.

## 타격 및 연출

- 타격 범위는 월드의 경계선과 HUD 원형 미리보기로 표시됩니다. 미리보기 크기는 선택한 반경에 맞춰 조정됩니다.
- 타격은 지정 좌표를 기준으로 수직 원기둥 범위에 적용됩니다.
- 요청 후 카운트다운 중에는 타격 범위 안의 플레이어에게 경고가 표시됩니다.
- 10초 컷씬은 우주 장면에서 동력 충전, 목표 고정, 대기권 진입을 거쳐 오버월드 타격 장면으로 이어집니다.
- 별의 항행 잔상, 행성 주위의 에너지 궤도, 스캔라인, 조준선, 카운트다운과 장면 전환 섬광이 컷씬을 장식합니다.
- 목표 지점에는 다중 색상의 비컨 빔이 나타나며, 지면을 따라 여러 겹의 충격파와 입자가 퍼집니다.
- 블록 파괴 시 폭발, 영혼 불꽃, 연기, 차원 입자 효과가 발생합니다. 빈 청크 섹션은 건너뛰고 한 틱에 최대 4개 청크를 처리해 넓은 범위의 정리를 최적화합니다.
- 타격으로 사망한 생명체는 요청 플레이어의 공격으로 처리됩니다. 플레이어 사망 메시지는 “(유저)은(는) 엔트로피 역전 프로토콜로 인하여 소멸되었습니다.”로 표시됩니다.

## 동작 및 제한

- 크리에이티브 및 관전 모드 플레이어는 엔티티 제거 대상에서 제외됩니다.
- 요청기는 소모되지 않으며, 타격 요청 후 10초의 재사용 대기시간이 있습니다.
- 조준 시 목표 지점과 반경 경계에 입자 효과가 표시됩니다. 조준 시작, 반경 변경, 컷씬 전환 및 타격 시 사운드가 재생됩니다.
- 요청기는 제작할 수 없으며 크리에이티브 모드에서 획득할 수 있습니다.
